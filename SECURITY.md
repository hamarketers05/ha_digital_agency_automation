# Security policy

- This repository is public by user choice; never commit secrets or access tokens.
- Do not store tokens in source, D1 plain-text fields, logs, issues, or status reports.
- Do not connect any AI Tech Lab Worker, database, or account secret to this repository.
- Review least-privilege permissions before adding GitHub, Meta, or research API secrets.
- User approval is required before enabling paid billing or making an architectural change that affects working resources.
- Responsible disclosures should be sent privately to the repository owner; do not include real credentials in the report.
